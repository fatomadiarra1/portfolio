🌐 **Site en ligne :** https://fatomadiarra.vercel.app

## Contenu

- Présentation et profil professionnel

## Lancer le projet en local

Le site est statique, aucune installation n'est nécessaire.

```bash
git clone https://github.com/fatomadiarra1/portfolio.git
cd portfolio
# Ouvrir index.html dans un navigateur, ou lancer un serveur local :
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Déploiement

Le site est déployé automatiquement sur Vercel à chaque push sur la branche `main`.
